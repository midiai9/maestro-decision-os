# Maestro AI OS

Landing page institucional do Maestro AI OS — camada estratégica de decisão empresarial da Always On.

## Stack

- React + Vite + TypeScript
- Tailwind CSS
- Framer Motion

## Desenvolvimento

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

## Deploy

Build automatizado via CI/CD. Saída em `dist/`.
